# Trollsound 1.0.3

## Novedades

- Mezcla continua del microfono predeterminado y los clips hacia VB-Cable.
- La voz permanece activa antes, durante y despues de cada macro.
- Escucha local del clip sin monitorizar la voz.
- Volumenes independientes para microfono, sonido enviado y escucha local.
- Atajos globales nativos de Windows activos con la ventana minimizada o en bandeja.
- Interrupcion inmediata del clip anterior sin interrumpir el puente del microfono.
- Migracion automatica de configuraciones anteriores al esquema 3.

## Configuracion necesaria

Selecciona `CABLE Input` en Trollsound y configura `CABLE Output` una sola vez como microfono en Discord, juego o aplicacion de voz. El microfono fisico debe permanecer como entrada predeterminada de Windows.

## Descargas

- `Trollsound-Setup-v1.0.3-x64.exe`: instalador recomendado para Windows 10/11 x64.
- `Trollsound-1.0.3-source.zip`: fuentes y scripts reproducibles.
- `SHA256SUMS.txt`: hashes para comprobar integridad.

## Notas

VB-Cable no se incluye en el instalador. Si falta, Trollsound ofrece abrir la descarga e instalacion oficial. El instalador de Trollsound no esta firmado, por lo que Windows puede mostrar SmartScreen.

Algunos juegos elevados, sistemas antitrampas, pulsar-para-hablar o filtros de supresion de ruido pueden afectar los atajos o la mezcla recibida.
