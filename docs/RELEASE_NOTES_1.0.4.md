# Trollsound 1.0.4

## Novedades

- Nueva ventana **Configuracion** con nombre del producto, version y creador.
- Boton **Donar con Cafecito** que abre el perfil oficial de Francisco Banegas.
- Atajo global configurable para detener inmediatamente el clip actual.
- El atajo de detencion funciona con Trollsound minimizado o en la bandeja.
- Detener un clip mantiene activo el puente del microfono y permite seguir hablando.
- Deteccion de conflictos entre el atajo de detencion, las macros y otras aplicaciones.
- Migracion automatica de configuraciones anteriores al esquema 4.

## Configuracion necesaria

Selecciona `CABLE Input` en Trollsound y configura `CABLE Output` una sola vez como microfono en Discord, juego o aplicacion de voz. El microfono fisico debe permanecer como entrada predeterminada de Windows.

## Descargas

- `Trollsound-Setup-v1.0.4-x64.exe`: instalador recomendado para Windows 10/11 x64.
- `Trollsound-1.0.4-source.zip`: fuentes y scripts reproducibles.
- `SHA256SUMS.txt`: hashes para comprobar integridad.

## Notas

VB-Cable no se incluye en el instalador. Si falta, Trollsound ofrece abrir la descarga e instalacion oficial. El instalador de Trollsound no esta firmado, por lo que Windows puede mostrar SmartScreen.

Algunos juegos elevados, sistemas antitrampas, pulsar-para-hablar o filtros de supresion de ruido pueden afectar los atajos o la mezcla recibida.
